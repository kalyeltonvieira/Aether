# Política de segurança

O Aether é um protótipo de pesquisa e não deve ser exposto como serviço público sem revisão de segurança própria.

Para reportar uma vulnerabilidade, use o recurso privado de **Security Advisories** do GitHub para este repositório, se estiver habilitado. Se o recurso não estiver disponível, entre em contato em privado com o mantenedor pelo perfil do GitHub antes de divulgar detalhes. Não publique dados sensíveis, credenciais, arquivos SNAP locais ou um exploit funcional em uma issue pública.

Não há prazo de resposta ou política de suporte garantidos neste momento. Atualizações sobre correções serão publicadas no repositório.
